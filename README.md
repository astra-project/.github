# .github

Organization-wide files for the [ASTRA Project](https://github.com/astra-project).

- [`profile/README.md`](profile/README.md) is the public profile shown on the organization's GitHub page.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`CONTRIBUTING.md`](CONTRIBUTING.md) and the issue forms in [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) are the defaults for every repository in the organization that doesn't have its own.
